#  Number Guessing Game (Python)

##  About the Project
This is a simple command-line Number Guessing Game built using Python.

The computer randomly generates a number within a range selected by the user. The player has to guess the randomly generated number until they get the correct answer.

The game also counts the number of attempts taken by the player to guess the correct number.

##  Features
- User-defined number range.
- Random number generation using Python's `random` module.
- Takes guesses from the user.
- Checks whether the guess is correct or incorrect.
- Provides feedback when the guess is too high.
- Counts the total number of guesses.
- Handles invalid inputs.

## 🛠️ Technologies Used
- **Python 3**
- **Random Module**

   ```bash

   ```

3. Run the Python file:

   ```bash
   python main.py
   ```

## 🎮 How to Play

1. Enter the maximum number for the guessing range.
2. The computer randomly selects a number between 0 and your chosen maximum.
3. Enter your guesses.
4. Keep guessing until you find the correct number.
5. The game displays the total number of attempts you took.
